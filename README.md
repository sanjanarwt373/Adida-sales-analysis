          Adidas Sales Analysis Dashboard
 
This project is all about taking a deep dive into Adidas sales data from the years 2024 and 2025.
Using Power BI and Excel, we want to figure out what's happening with the sales numbers and make sense of the trens.

 Tools and Data Source
 
Here Excel and Power BI used to handle and visualize the data and this data was extract from Kaggle and Google to keep things updated and relevant.

 Features and Highlights
 
-With the help of this dashboard we're tackling the main sales challenges Adidas is facing in those years and Power BI will help us to create easy to understand visuals.

-We'll use card and charts that really show the important sales metrics.

-The goal is to get clear ,actionable insights so the business can make informed decisions.
